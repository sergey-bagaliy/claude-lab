# ИИ-агентство в Краснодаре

Три части проекта:

| Папка | Что внутри | С чего начать |
|---|---|---|
| [`research/`](research/) | Исследование и бизнес-план: ниши, конкуренты и цены, пакеты, себестоимость, 152-ФЗ, первые клиенты, план на 90 дней, риски | [`research/README.md`](research/README.md) или `research/report.html` (открыть в браузере) |
| [`site/`](site/) | Лендинг агентства для GitHub Pages: услуги, демо, пакеты, форма заявки, политика и согласие | [`site/README.md`](site/README.md) |
| [`bot/`](bot/) | Шаблон «ИИ-администратора» — Telegram-бот на Python (aiogram 3 + Claude), запись клиентов, ответы по базе знаний, заявки владельцу | [`bot/README.md`](bot/README.md) |

Принципы:
- **Цифры только со ссылками.** Чего не нашли, помечено «нужно уточнить».
- **Ключи только в переменных окружения.** В репозитории их нет, это проверяет тест `bot/tests/test_no_secrets.py`.
- **Без выдуманных кейсов и отзывов.** На сайте только демо-сценарии, явно помеченные как демо.
