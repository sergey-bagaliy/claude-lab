# Калькулятор материалов для ремонта

Сайт для телефона: вводите комнаты — получаете, сколько купить плитки, ламината, краски, обоев,
штукатурки, грунта и шпаклёвки, и сколько это стоит по вашим ценам. Расчёт можно сохранить,
отправить списком в мессенджер и распечатать (или сохранить) в PDF.

Адрес после включения GitHub Pages (см. ниже):
**https://sergey-bagaliy.github.io/claude-lab/remont-calc/**

---

## Как пользоваться

Внизу экрана три вкладки: **Комнаты → Материалы → Итог**. Вверху всегда видна общая сумма.

### 1. Комнаты

1. Введите **длину, ширину и высоту** комнаты в метрах. Дробь — через запятую: `2,7`.
2. Добавьте **окна и двери** кнопками «+ Окно» / «+ Дверь» и поправьте размеры.
   Одинаковые окна можно записать одной строкой, указав количество в поле «Шт.».
3. Выберите **отделку**:
   - Пол: ламинат / плитка / нет;
   - Стены: покраска / обои / плитка / нет;
   - Потолок: покраска / нет.
4. Отметьте **подготовку**: штукатурка, шпаклёвка, грунт — отдельно для стен, потолка и пола.
5. Под каждой комнатой сразу видно: площадь пола, площадь стен без проёмов и периметр.

Кнопки у названия комнаты: копировать (удобно для одинаковых спален), удалить, свернуть.
Новая комната берёт высоту потолка из предыдущей.

Пример: спальня 4 × 3 м, потолок 2,7 м, окно 1,4 × 1,5, дверь 0,9 × 2,1 →
пол 12 м², стены 37,8 − 3,99 = 33,81 м².

### 2. Материалы

У каждого материала — параметры упаковки, норма расхода, **запас в %** и **цена**.
Карточки материалов, которые выбраны в комнатах, раскрыты; остальные свёрнуты.

- Значения по умолчанию — **типовые**. Перед покупкой сверьте их с упаковкой своего материала
  и исправьте: размер плитки и штуки в коробке, м² в пачке ламината, расход краски, вес мешка и т. д.
- Цены вводите свои. У плитки и ламината можно выбрать, за что цена — **за м²** или **за упаковку**.
- Кнопка «Вернуть типовые нормы» сбрасывает нормы и запас, **цены не трогает**.

### 3. Итог

- По каждому материалу: **сколько купить** (целые упаковки), сумма и строка «откуда взялись цифры».
- Ниже — разбивка по комнатам.
- Если какая-то цена не введена, итог пометит это.

**Сохранить** — расчёт попадает в список «Сохранённые расчёты» (хранится в браузере этого телефона).
Название берётся из поля «Объект».
**Новый расчёт** — чистый лист; цены и нормы переносятся из текущего.
**Скачать файл / Загрузить файл** — перенос расчёта на другой телефон или компьютер, резервная копия.
**Отправить список** — короткий список покупок через WhatsApp, Telegram и т. п.
(на компьютере — копируется в буфер обмена).

### PDF и печать

Нажмите **«PDF / печать»** — откроется окно печати с отдельной версией страницы:
таблица комнат, таблица материалов с расчётом и итог.

- **Android (Chrome):** в окне печати вверху выберите принтер «Сохранить как PDF» → кнопка PDF.
- **iPhone (Safari):** в окне печати нажмите «Поделиться» → «Сохранить в Файлы»
  (или разведите двумя пальцами превью — откроется PDF).
- **Компьютер:** «Сохранить как PDF» в списке принтеров.

Если сайт открыт как приложение с главного экрана и окно печати не появляется —
откройте тот же адрес в обычном браузере и нажмите кнопку там.

### На главный экран и без интернета

- Android: меню Chrome → «Добавить на главный экран».
- iPhone: Safari → «Поделиться» → «На экран „Домой“».

После первого открытия сайт работает **без интернета** (например, в подвале или на объекте без связи).
Расчёты хранятся в памяти браузера телефона: если очистить данные браузера, они пропадут —
для надёжности скачивайте файл расчёта.

## Формулы

Все формулы — в файле [`formulas.js`](formulas.js), с комментариями. На них есть тесты — [`tests/formulas.test.js`](tests/formulas.test.js).

Обозначения: ⌈x⌉ — округление вверх до целого, ⌊x⌋ — вниз. «Запас» — процент, который задаётся у каждого материала.

### Площади комнаты

| Что | Формула |
|---|---|
| Пол, потолок | длина × ширина |
| Периметр | 2 × (длина + ширина) |
| Стены «грязные» | периметр × высота |
| Окна и двери | Σ (ширина × высота × количество) |
| Стены «чистые» | стены «грязные» − окна и двери |

Какая площадь идёт под материал:

- ламинат, плитка на пол, грунт пола — площадь пола;
- покраска стен, плитка на стены, штукатурка/шпаклёвка/грунт стен — «чистая» площадь стен;
- покраска потолка, штукатурка/шпаклёвка/грунт потолка — площадь потолка;
- обои — считаются полосами по периметру (см. ниже).

**Площади всех комнат по каждому материалу складываются, и только потом считаются упаковки.**
Так меньше лишнего: две комнаты по 3 м² ламината — это 3 пачки на обе, а не 2 + 2.

### Плитка

```
площадь одной плитки = (длина, см ÷ 100) × (ширина, см ÷ 100)
плиток, шт = ⌈ площадь × (1 + запас %) ÷ площадь плитки ⌉
упаковок   = ⌈ плиток ÷ штук в упаковке ⌉
стоимость  = упаковок × м² в упаковке × цена за м²   (или упаковок × цена за упаковку)
```
Пример: пол 12 м², плитка 60 × 60, 4 шт. в упаковке, запас 10 % → 13,2 м² → 37 шт. → **10 упаковок** (14,4 м²).

### Ламинат

```
упаковок  = ⌈ площадь × (1 + запас %) ÷ м² в упаковке ⌉
стоимость = упаковок × м² в упаковке × цена за м²   (или упаковок × цена за упаковку)
```
Пример: 20 м², запас 7 %, в пачке 2,397 м² → 21,4 м² → **9 упаковок**.

### Краска (стены и потолок отдельно)

```
литров    = площадь × слоёв ÷ укрывистость (м² с 1 литра) × (1 + запас %)
банок     = ⌈ литров ÷ объём банки ⌉
стоимость = банок × цена банки
```
Пример: 33,9 м², 2 слоя, 8 м²/л, запас 10 % → 9,32 л → **2 банки по 9 л**.
Если на банке расход указан в л/м², укрывистость = 1 ÷ расход (0,125 л/м² = 8 м²/л).

### Обои

Считаются **полосами**, а не делением площади на площадь рулона — так точнее.

```
длина полосы   = высота + припуск
                 (если есть раппорт — округляется вверх до целого числа раппортов)
полос в рулоне = ⌊ длина рулона ÷ длина полосы ⌋
полос          = ⌈ периметр ÷ ширина рулона ⌉        (по каждой комнате)
полос с запасом = ⌈ полос × (1 + запас %) ⌉
рулонов        = ⌈ полос с запасом ÷ полос в рулоне ⌉
стоимость      = рулонов × цена рулона
```
Пример: периметр 14 м, высота 2,7 м, рулон 1,06 × 10,05 м, припуск 0,1 м →
полоса 2,8 м, 3 полосы из рулона, 14 полос → **5 рулонов**.

- Окна и двери по умолчанию **не вычитаются**: обрезки уходят на участки над дверями и под окнами.
  Можно включить «Вычитать ширину окон и дверей» — тогда из периметра вычитается их ширина.
- Комнаты с одинаковой высотой считаются вместе (остаток рулона идёт в соседнюю комнату),
  с разной высотой — отдельно, рулоны складываются.

### Штукатурка и шпаклёвка

```
кг        = площадь × расход (кг/м² на 1 мм) × толщина слоя (мм) × (1 + запас %)
мешков    = ⌈ кг ÷ вес мешка ⌉
стоимость = мешков × цена мешка
```
Пример: 33,9 м² × 0,85 кг/м²/мм × 10 мм × 1,1 = 317 кг → **11 мешков по 30 кг**.

### Грунт

```
литров    = площадь × расход (л/м² на 1 слой) × слоёв × (1 + запас %)
канистр   = ⌈ литров ÷ объём канистры ⌉
стоимость = канистр × цена канистры
```
Пример: 57,9 м² × 0,15 л/м² × 2 слоя × 1,1 = 19,1 л → **2 канистры по 10 л**.

### Что калькулятор не считает

Клей для плитки, затирку, подложку под ламинат, плинтус, откосы окон и дверей, короб и ванну
в санузле, малярную сетку и инструмент. Плитка на стенах считается на всю высоту комнаты.

## Как опубликовать на GitHub Pages

Сайт — обычные файлы, сборка не нужна.

1. Слейте ветку с калькулятором в `main` (через Pull Request).
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт откроется по адресу
   `https://sergey-bagaliy.github.io/claude-lab/remont-calc/`.

GitHub Pages на бесплатном тарифе работает только для **публичных** репозиториев.

Проверить локально на компьютере: открыть `index.html` двойным щелчком
(всё работает, кроме режима без интернета) или запустить в папке `python3 -m http.server`
и открыть http://localhost:8000.

## Для разработчика

| Файл | Что внутри |
|---|---|
| `formulas.js` | все формулы и типовые нормы, без привязки к странице |
| `app.js` | интерфейс: ввод, итог, сохранение, печать |
| `index.html`, `style.css` | разметка и стили (сначала телефон) |
| `sw.js` | работа без интернета (кэш файлов сайта) |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | установка на главный экран |
| `tests/formulas.test.js` | тесты формул |

Тесты (нужен Node.js 18+, зависимостей нет):

```
cd remont-calc
npm test
```

Тесты запускаются автоматически на GitHub при каждом изменении папки (`.github/workflows/remont-calc-tests.yml`).

После изменения файлов сайта увеличьте номер версии `CACHE` в `sw.js` (`remont-calc-v1` → `v2`),
иначе у пользователей может открываться старая копия из кэша (обновится при следующем открытии).
