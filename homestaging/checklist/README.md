# Чек-лист «Подготовка квартиры к фотосъёмке»

Печатный чек-лист для риелторов в формате PDF (A4, 2 страницы). Он помогает подготовить квартиру клиента к съёмке для объявления о продаже или аренде. На первой странице: шапка с полями «Адрес / Дата и время / Ответственный», разделы «За 3–5 дней до съёмки», «Накануне съёмки» и начало раздела «По комнатам». На второй: остальные комнаты, «В день съёмки», «Для фотографа — кратко», «Безопасность и честность» и блок с предложением помощи и контактами.

Бренд «Хоумстейджинг Краснодар» — рабочее название, его можно заменить (см. ниже). Чек-лист рассчитан на чёрно-белую печать: квадратики для отметок размером 4,6 мм, основной текст 10 pt.

## Файлы

| Файл | Что это |
|---|---|
| `checklist.html` | Исходник: вся вёрстка, тексты, стили и иконки в одном файле, внешних ресурсов нет |
| `build.js` | Сборка PDF через Playwright (Chromium) |
| `checklist.pdf` | Готовый файл для печати и рассылки |

## Как пересобрать PDF

Из корня репозитория:

```bash
node homestaging/checklist/build.js
```

Нужны Node.js и пакет `playwright` с установленным Chromium (`npm i playwright && npx playwright install chromium`, если их нет). Скрипт пишет число страниц и предупреждает, если текст листа перестал помещаться на страницу. В таком случае он завершается с кодом 2.

## Название и контакты

В самом начале `checklist.html` есть блок настроек в HTML-комментарии:

```
BRAND_NAME: Хоумстейджинг Краснодар
CONTACT_PHONE:
CONTACT_EMAIL:
CONTACT_SITE:
CONTACT_TELEGRAM:
```

1. Впишите значения после двоеточия. Телефон можно указать в любом виде, сайт — с `https://` или без, Telegram — как `@имя` или ссылку `t.me/…`.
2. Запустите `node homestaging/checklist/build.js`.

`build.js` подставит название в шапку, подвал и метаданные PDF, а контакты — отдельной строкой внизу второй страницы. Телефон, почта, сайт и Telegram в PDF становятся кликабельными. Пустые поля не выводятся. Если не заполнен ни один контакт, в подвале остаются только название и строка «Подготовка квартир к продаже и сдаче в Краснодаре». Проверено: даже с четырьмя длинными контактами чек-лист помещается на 2 страницы.

## Как править тексты

- Каждый пункт — это `<li>` внутри `<ul class="check">`. Квадратик рисуется через CSS, ничего добавлять не нужно.
- Две страницы — это два блока `<section class="sheet">`. Блоки внутри не переносятся на другую страницу автоматически. Если после правки `build.js` пишет «лист N не помещается», сократите формулировки или перенесите блок (например, комнату) на другой лист.
- Пишите обычными пробелами. При сборке `build.js` сам расставляет неразрывные пробелы: после коротких слов («в шкаф», «и стулья»), перед тире и между числом и словом («3–5 дней»). Кавычки «ёлочки», тире «—» и букву «ё» ставьте в тексте сами.
- Номер страницы («стр. 1 из 2») и строка в нижнем колонтитуле задаются в CSS, в правиле `@page`.
- Цвета вынесены в переменные в `:root` и совпадают с сайтом: `--text`, `--muted`, `--line`, `--accent`, `--accent-soft`. Шрифт — Inter, он должен быть установлен в системе. Если его нет, используется DejaVu Sans.

Чтобы быстро посмотреть результат, откройте `checklist.html` в браузере: листы показываются как страницы A4. Контакты, изменённое название и неразрывные пробелы появляются только в PDF после сборки.

## Принципы содержания

В чек-листе нет статистики, процентов, обещаний сроков продажи, отзывов и других числовых утверждений. Есть только практические указания вроде «за 3–5 дней». Раздел «Безопасность и честность» напоминает: фото должны соответствовать квартире, а виртуальная расстановка мебели допустима только с пометкой. При правке текстов сохраняйте эти правила.
