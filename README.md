# claude-lab

- [remont-calc](remont-calc/) — калькулятор материалов для ремонта (сайт для телефона): 132 вида материалов — отделка, черновые и плиточные работы, окна и двери, электрика, сантехника, отопление; раздельный расчёт по помещениям, сравнение вариантов, смета для заказчика в PDF и выгрузка в Excel. Описание и формулы — в [remont-calc/README.md](remont-calc/README.md).
