# 🏠 «Семейный помощник» — Telegram-бот на Claude

Бот для семьи из Краснодара: Сергей, Вика, Никита (8 лет) и Катя (3 года).
Берёт на себя бытовые мелочи: рецепты, список покупок, напоминания,
занятия с детьми, идеи на выходные. Отвечает на любые вопросы
и может сам поискать свежую информацию в интернете.

> 📋 **Коротко, как запускать и останавливать бота на компьютере, — в памятке [ЗАПУСК.md](ЗАПУСК.md).**

## Что умеет

Внизу экрана — меню из кнопок:

```
┌────────────────────┬────────────────────┐
│ 🍲 Рецепт с фото   │ 🛒 Покупки         │
├────────────────────┼────────────────────┤
│ ⏰ Напоминания     │ 🌳 Выходные        │
├────────────────────┼────────────────────┤
│ 🧮 Примеры Никите  │ 📖 Сказка Кате     │
├────────────────────┼────────────────────┤
│ 🧹 Новый разговор  │ ⚙️ Настройки       │
└────────────────────┴────────────────────┘
```

| Кнопка | Что делает | Платно? |
|---|---|---|
| 🍲 **Рецепт с фото** | Находит настоящий рецепт в интернете и присылает карточку: фото блюда, продукты, шаги, совет для детей. Кнопки «🛒 Продукты в покупки» и «🔄 Другой рецепт» | да |
| 🛒 **Покупки** | Общий список для всей семьи. Нажали на товар — отмечен купленным | **нет** |
| ⏰ **Напоминания** | Разовые и **повторяющиеся** (каждый день, по будням, по выходным, раз в неделю). Список с кнопками удаления. Разовое приходит с кнопками «✅ Сделано», «+15 мин», «+1 час», «Завтра», повторяющееся — с «🔕 Больше не присылать» | создание — да, остальное — нет |
| 📬 **Рассылки** (просто напишите) | «Каждое утро присылай интересный факт», «по будням в 7:30 — мотивирующую мысль», «каждое утро — погоду в Краснодаре». Каждый раз новый текст от Claude, без повторов | да, копейки за выпуск |
| 🌳 **Выходные** | Ищет прогноз погоды в Краснодаре и предлагает идеи. Кнопки «Дома», «В городе», «Поездка» | да |
| 🧮 **Примеры Никите** | Тренажёр таблицы умножения: 4 варианта ответа на кнопках, баллы, похвала, разбор ошибок. Есть режим «списком» | **нет** |
| 📖 **Сказка Кате** | Добрая сказка на ночь, Катя — главная героиня. Перед сказкой — настоящие фото её героев (ёжик, белочка, звёздное небо). Темы: зверята, космос, волшебство. Под сказкой кнопки «🔊 Прочитать вслух», «🎧 Аудиосказки» и «🎬 Мультфильмы» | да (озвучка — бесплатно) |
| 🏖 **Фото мест** (просто напишите) | «покажи фото Геленджика», «курорты Черноморского побережья с фото» — альбом настоящих фотографий | да |
| 🔗 **Видео и ссылки** (просто напишите) | «найди видео, как сделать кормушку с Никитой» — подборка ссылок с превью | да |
| 🎤 **Голосовые** (просто запишите) | Распознаёт речь и отвечает текстом и голосом. Распознавание и озвучка работают на вашем сервере, бесплатно | ответ Claude — да, голос — нет |
| ⚙️ **Настройки** | Кто отвечает: ⚡ **Haiku** (быстро и экономно) или 🧠 **Sonnet** (умнее, дороже) — одной кнопкой. Отвечать ли голосом. Сколько потрачено и какой лимит | нет |
| 🧹 **Новый разговор** | Забыть историю переписки. Покупки и напоминания остаются | нет |

**Главное — можно просто писать обычными словами:**
- «добавь в покупки молоко, хлеб и яйца»
- «напомни завтра в 8:00 взять Никите форму на физкультуру»
- «напомни Вике в 17:30 забрать Катю из садика» — придёт Вике
- «напоминай мне каждое утро в 8:00, что нужно добиваться своих целей»
- «каждое утро присылай интересный факт» / «перестань присылать факты»
- «что приготовить из курицы и риса?»
- «покажи фото Абрау-Дюрсо и Анапы»
- «найди мультик про ёжика для Кати»
- «какая погода в субботу?» — бот поищет в интернете и даст ссылки на источники

**Откуда фото, видео и аудио.** Нейросеть не рисует картинки и не записывает видео — бот
присылает настоящие материалы из интернета:
- **Рецепты** — Claude находит рецепт на кулинарном сайте, Telegram показывает крупное фото со страницы над текстом.
  Если у сайта нет картинки для превью, рецепт придёт без фото, но со всем остальным.
- **Фото мест** — из [Wikimedia Commons](https://commons.wikimedia.org/): там миллионы фото со свободными лицензиями,
  ключ не нужен. Под каждым фото — автор и лицензия.
- **Мультфильмы, аудиосказки, видео** — Claude ищет их в интернете, бот присылает ссылки с превью
  (у видео — кадр, нажали — открылось). Файлы с YouTube и других сайтов бот не скачивает: это нарушало бы их правила.
- **Защита от выдуманных ссылок.** Нейросети иногда «придумывают» адреса, особенно на YouTube. Бот показывает
  только ссылки, которые действительно нашлись в поиске; остальные отбрасывает и просит Claude поискать ещё.
- **Картинки к сказкам** — тоже настоящие фото из Wikimedia Commons: Claude выбирает, кого показать (главного героя или место действия).
- **Голос** — Claude не умеет говорить, поэтому озвучка и распознавание речи работают отдельно, бесплатно, на вашем
  сервере: распознавание — Whisper, озвучка — Piper с русским голосом (раздел 5).

Сделано на **Python** + **aiogram 3** (Telegram) + **anthropic** (официальная библиотека Claude API).
Модель — **Claude Haiku 5.5** (`claude-haiku-5-5`): быстрая и экономная. Можно переключить на более умную Sonnet (см. [раздел 7](#7-настройки)).

## 1. Получаем токен бота у @BotFather

Токен — это «пароль» бота. С ним программа может отвечать от имени бота.

1. Откройте Telegram и найдите **@BotFather** (у него синяя галочка).
2. Нажмите «Старт» и отправьте команду `/newbot`.
3. BotFather спросит **имя** — оно будет видно в чате. Например: `Семейный помощник`.
4. Потом спросит **username** — адрес бота. Он должен заканчиваться на `bot` и быть свободным.
   Например: `family_helper_krd_bot`. Если занято — придумайте другой.
5. BotFather пришлёт сообщение с токеном вида `1234567890:AAH...` (длинная строка через двоеточие).
   **Это и есть `TELEGRAM_BOT_TOKEN`.** Скопируйте его целиком.

> 🔒 Токен никому не показывайте и не выкладывайте в интернет.
> Если он «утёк» — в @BotFather: `/mybots` → ваш бот → **API Token** → **Revoke current token**.
> Старый токен перестанет работать, BotFather выдаст новый.

Аватарку можно поставить там же: `/setuserpic`. Меню команд и описание бота программа настроит сама при запуске.

Источник: [официальная инструкция Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

## 2. Получаем API-ключ в Claude Console

API-ключ — это «пароль» для доступа к Claude из программы. Оплата идёт за каждый запрос.

1. Откройте **[platform.claude.com](https://platform.claude.com/)** и войдите или зарегистрируйтесь.
2. Пополните баланс в разделе **Billing**. Начните с небольшой суммы (см. [раздел 8](#8-сколько-это-стоит)).
3. Откройте страницу **[API keys](https://platform.claude.com/settings/keys)** (`platform.claude.com/settings/keys`).
4. Нажмите **Create key**, назовите ключ, например `family-bot`, и создайте его.
5. Скопируйте ключ — он начинается с `sk-ant-`. **Ключ показывают только один раз.**
   Потеряли — просто создайте новый.
   **Это и есть `ANTHROPIC_API_KEY`.**

Важно знать:

- **Подписка Claude Pro/Max и API — это разные вещи.** Подписка не оплачивает запросы через API, баланс в Console пополняется отдельно.
  Источник: [справка Anthropic](https://support.claude.com/en/articles/9876003).
- **Поиск в интернете** (рецепты, видео, аудио, погода, афиша) включён по умолчанию. Администратор может отключить его в Console на странице [Capabilities](https://platform.claude.com/settings/capabilities).
  Если поиск отключён, бот сам это заметит и продолжит работать без него, только рецепты придут без фото, а видео и аудио не найдутся. Фото мест работают и без поиска.
  Источник: [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool).
- **Страны.** У Anthropic есть официальный список стран, откуда поддерживается доступ к API.
  На момент написания (ноябрь 2026) **России в этом списке нет**.
  Пользоваться API нужно по правилам Anthropic.
  Источник: [Supported regions](https://platform.claude.com/docs/en/api/supported-regions).

Источник по ключам: [Get your Claude API key](https://platform.claude.com/docs/en/get-api-key).

## 3. Запуск на Windows по шагам

### Шаг 3.1. Установите Python

1. Скачайте Python **3.12 или 3.13** с [python.org/downloads/windows](https://www.python.org/downloads/windows/).
2. При установке **обязательно поставьте галочку «Add python.exe to PATH»**, потом нажмите «Install Now».
3. Проверьте: откройте PowerShell (Пуск → наберите `PowerShell` → Enter) и введите:

   ```powershell
   python --version
   ```

   Должно показать `Python 3.13.…`. Если открылся Microsoft Store — Python не установлен или не стоит галочка PATH. Переустановите с галочкой.

### Шаг 3.2. Скачайте проект

На странице репозитория на GitHub нажмите зелёную кнопку **Code** → **Download ZIP**.
Распакуйте архив, например, в `C:\bots\`. Нужная папка — `telegram-bot`.

### Шаг 3.3. Откройте PowerShell в папке бота

Откройте папку `telegram-bot` в Проводнике, щёлкните по адресной строке сверху,
наберите `powershell` и нажмите Enter. Откроется окно PowerShell сразу в этой папке.

### Шаг 3.4. Установите библиотеки

Создаём «виртуальное окружение» — отдельную папку `.venv` с библиотеками только для этого бота:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Займёт 1–2 минуты. Это нужно сделать один раз (и повторить после обновления бота).

### Шаг 3.5. Задайте ключи (переменные окружения)

Ключи **не пишутся в файлы проекта**. Их берут из переменных окружения Windows.

**Вариант А — навсегда (удобнее).** Выполните в PowerShell, подставив свои значения:

```powershell
setx TELEGRAM_BOT_TOKEN "сюда_токен_от_BotFather"
setx ANTHROPIC_API_KEY "сюда_ключ_из_Claude_Console"
```

После этого **закройте PowerShell и откройте заново** (шаг 3.3) — `setx` действует только на новые окна.
Значения сохраняются в настройках вашей учётной записи Windows, а не в папке проекта.

Проверить можно так (покажет первые символы, а не весь ключ):

```powershell
$env:ANTHROPIC_API_KEY.Substring(0, 10)
```

**Вариант Б — только для текущего окна** (закрыли окно — ключи забылись):

```powershell
$env:TELEGRAM_BOT_TOKEN = "сюда_токен_от_BotFather"
$env:ANTHROPIC_API_KEY = "сюда_ключ_из_Claude_Console"
```

### Шаг 3.6. Запустите бота

```powershell
.venv\Scripts\python main.py
```

Или просто дважды щёлкните файл **`start-bot.bat`** в папке бота.

Если всё хорошо, появится строка:

```
... INFO family_bot.app: Бот @family_helper_krd_bot запущен. Модель: claude-haiku-5-5. Остановить: Ctrl+C
```

Откройте своего бота в Telegram и отправьте `/start` — появится меню из кнопок. 🎉

**Бот работает, пока открыто это окно.** Остановить — `Ctrl+C` или закрыть окно.
Рядом с ботом появятся файлы `family_bot.db` (покупки, напоминания, история) и `bot.log` (журнал работы).

### Шаг 3.7. Пустите только семью (рекомендуется)

Сейчас бот отвечает **любому**, кто его найдёт, и тратит ваши деньги. Ограничим доступ:

1. Узнайте свой Telegram ID. Остановите бота (`Ctrl+C`) и выполните:

   ```powershell
   $env:ALLOWED_USER_IDS = "1"
   .venv\Scripts\python main.py
   ```

   Напишите боту что угодно — он ответит: «Ваш Telegram ID: 123456789». Пусть то же сделает Вика.
2. Сохраните ID через запятую и перезапустите бота в **новом** окне PowerShell
   (если ключи задавали вариантом Б — задайте их в новом окне снова):

   ```powershell
   setx ALLOWED_USER_IDS "123456789,987654321"
   ```

Теперь чужим бот отвечает только «это семейный бот» — без запроса к Claude, бесплатно.

### Шаг 3.8. Подключите Вику

Пусть Вика найдёт бота и нажмёт **«Старт»**. Это нужно один раз: Telegram не разрешает ботам писать
тем, кто сам их не запускал. После этого работают «напомни Вике…», общий список покупок
и всё остальное — у каждого своя переписка с ботом.

## 4. Работа 24/7: сервер с Docker

Бот работает, пока запущена программа. Напоминания и резервные копии — тоже.
Поэтому для работы круглосуточно лучше всего недорогой сервер (VPS) — компьютер в дата-центре,
который никогда не выключается. Бот сам обращается к Telegram, поэтому **белый IP, домен и HTTPS не нужны**.

Бот запускается в **Docker** — это «коробка», в которой уже лежит всё нужное: Python, библиотеки, голос.
Ставить ничего вручную не надо, а после перезагрузки сервера бот поднимается сам.

> ⚠️ **Где должен стоять сервер.** Anthropic поддерживает доступ к Claude не из всех стран — вот
> [официальный список](https://platform.claude.com/docs/en/api/supported-regions). **России в нём нет**
> (проверено в ноябре 2026): с российского сервера Claude, скорее всего, будет отвечать ошибкой
> «Claude отказал в доступе (403)». Берите сервер в стране из списка — например, в Нидерландах или Германии.
> Пользоваться API нужно по правилам Anthropic.

### 4.1. Какой сервер нужен

| | Без голоса | С голосом (по умолчанию) |
|---|---|---|
| Процессор | 1 ядро | 2 ядра |
| Память | 1 ГБ | **2 ГБ** (с 1 ГБ — поставьте `WHISPER_MODEL=base`) |
| Диск | 10 ГБ | 20 ГБ |
| Система | Ubuntu 24.04 | Ubuntu 24.04 |

Откуда цифры: образ бота с голосом весит около 1 ГБ (я собрал и измерил: 965 МБ), модель распознавания
`small` — около 0,5 ГБ на диске и примерно столько же в памяти, голос Piper — несколько десятков мегабайт.
Это мои оценки, на практике оставьте запас.

### 4.2. Сколько стоит сервер

Цены ниже — **с сайтов-обзоров и агрегаторов** (официальные страницы хостингов мне открыть не удалось),
источники расходятся, цены меняются. Перед оплатой сверьте на официальном сайте.

| Хостинг | Где | Конфигурация | Цена в месяц | Источники цены | Официальный сайт |
|---|---|---|---|---|---|
| **Hetzner Cloud** | Германия, Финляндия | 2 ядра, 4 ГБ | около €4–6,5 (тариф CX22 заменён на CX23; в 2026 году были повышения цен) | [сравнение 2026-08](https://kimmo.suominen.com/stuff/cpc-2026-08.txt), [Better Stack](https://betterstack.com/community/guides/web-servers/hetzner-cloud-review/), [whtop.com](https://www.whtop.com/plans/hetzner.com/144095) | [hetzner.com](https://www.hetzner.com/cloud/) |

Подойдёт любой хостинг в поддерживаемой стране с параметрами из раздела 4.1 и системой Ubuntu 24.04 —
все шаги ниже для него одинаковые.

### 4.3. Подключитесь к серверу

После оплаты хостинг пришлёт **IP-адрес** и **пароль** (выберите систему Ubuntu 24.04).
На Windows откройте PowerShell и выполните (вместо `1.2.3.4` — ваш IP):

```powershell
ssh root@1.2.3.4
```

На вопрос `Are you sure you want to continue connecting` ответьте `yes`, потом введите пароль
(при вводе символы не видны — это нормально). Все команды ниже выполняются уже на сервере.

### 4.4. Установите Docker

```bash
apt update && apt install -y docker.io docker-compose-v2 git
systemctl enable --now docker      # Docker будет запускаться сам при включении сервера
docker compose version             # проверка: должна показаться версия
```

### 4.5. Скачайте бота и задайте настройки

```bash
git clone -b claude/hopeful-wright-vu62xd https://github.com/sergey-bagaliy/claude-lab.git
cd claude-lab/telegram-bot

cp .env.example .env
nano .env          # впишите токен, ключ, свой Telegram ID; сохранить — Ctrl+O, Enter, выйти — Ctrl+X
chmod 600 .env     # файл с ключами сможет читать только владелец

mkdir -p data models
chown -R 1000:1000 data models     # бот в контейнере работает от пользователя 1000, ему нужно право записи
```

`-b claude/hopeful-wright-vu62xd` — ветка, где лежит эта версия бота. Когда её сольют в `main`, эту часть можно убрать.
Ключи живут только в файле `.env` на сервере: в образ Docker и в git они не попадают.

### 4.6. Запустите

```bash
docker compose up -d --build
docker compose logs -f             # смотреть журнал; Ctrl+C — выйти из просмотра (бот продолжит работать)
```

Первая сборка занимает несколько минут. При первом запуске бот скачает модели для голоса (ещё несколько минут) —
в журнале появится «Модель распознавания речи готова» и «Модель озвучки готова».
Когда увидите «Бот @… запущен», напишите боту в Telegram.

**Если сборка не может скачать базовый образ** (ошибка вида `failed to resolve reference "docker.io/library/python…"`):
Docker Hub бывает недоступен или ограничивает скачивания. Подключите зеркало — я проверил, что зеркало Google
`mirror.gcr.io` отдаёт нужный образ:

```bash
echo '{"registry-mirrors": ["https://mirror.gcr.io"]}' > /etc/docker/daemon.json
systemctl restart docker
docker compose up -d --build
```

### 4.7. Автозапуск после перезагрузки

Ничего настраивать не нужно: в `docker-compose.yml` стоит `restart: unless-stopped`,
а Docker включён в автозапуск (шаг 4.4). Проверьте один раз:

```bash
reboot
# подождите минуту, снова подключитесь по ssh, затем:
cd claude-lab/telegram-bot && docker compose ps      # в колонке STATUS должно быть «Up»
```

Если бот упадёт из-за сбоя, Docker тоже перезапустит его сам.

### 4.8. Резервные копии базы

- **Каждый день в 03:30 по Москве** (и сразу при запуске, если сегодняшней копии ещё нет) бот сохраняет копию
  базы в `data/backups/family_bot-ГГГГ-ММ-ДД.db`. Хранятся последние 14 дней (`BACKUP_KEEP_DAYS`).

  и она будет храниться в вашем чате с ботом.
- **Скачать копию на компьютер** (в PowerShell на Windows, вместо даты и IP — свои):

- **Восстановить из копии:**

  ```bash

  ```

Можно и без сервера — бот будет работать, пока включён компьютер:
1. Отключите спящий режим: Параметры → Система → Питание → настройки сна → **Никогда**.

## 5. Голосовые сообщения

- **Можно говорить вместо того, чтобы печатать.** Бот распознает голосовое, покажет, что услышал
  («🎤 «добавь молоко»»), и ответит **текстом и голосом**.
- Если бот ждал ответ (например, после «🍲 Рецепт с фото» или «➕ Добавить» в покупках), голосовое пойдёт туда же.
- Под сказкой для Кати — кнопка **«🔊 Прочитать вслух»**.
- Отвечать голосом или только текстом — переключатель в «⚙️ Настройках».

**Как это работает и сколько стоит.** Всё бесплатно и работает на вашем сервере или компьютере:
- распознавание речи — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (модель Whisper, лицензия MIT);
- озвучка — [Piper](https://github.com/OHF-Voice/piper1-gpl) (лицензия GPL-3.0) с русским голосом.

Модели скачиваются **один раз** с Hugging Face в папку `models`. **Сам звук никуда не отправляется**:
в Claude уходит только распознанный текст — как если бы вы его напечатали.

**Настройки голоса** (в `.env` или переменных окружения):

| Что | Переменная | Варианты |
|---|---|---|
| Модель распознавания | `WHISPER_MODEL` | `small` — по умолчанию, хорошо понимает русский; `base` — легче (для сервера с 1 ГБ), но ошибается чаще; `medium` — точнее, но нужно больше памяти и времени |
| Голос | `PIPER_VOICE` | `ru_RU-irina-medium` (женский, по умолчанию), `ru_RU-denis-medium`, `ru_RU-dmitri-medium`, `ru_RU-ruslan-medium` (мужские) — [список голосов](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU) |
| Выключить голос | `VOICE=0` | бот будет вежливо просить писать текстом |

Ограничения: голосовое — до 2 минут; голосовые обрабатываются по одному, чтобы не перегружать сервер.
Распознавание обычно занимает несколько секунд, на слабом сервере — дольше.

**На сервере (Docker)** голос включён сразу. Собрать лёгкий образ без голоса: `docker compose build --build-arg WITH_VOICE=0`.

**На Windows** голос нужно установить отдельно (около 1 ГБ):

```powershell
.venv\Scripts\python -m pip install -r requirements-voice.txt
```

Я проверял голосовые библиотеки на Linux (в том числе в Docker-образе), на Windows — нет. Если не установятся,
пользуйтесь голосом на сервере.

**Если сервер не может скачать модели** (Hugging Face недоступен; в журнале «Модель … не загрузилась»):
скачайте их на компьютере с установленным голосом и перенесите на сервер.

```powershell
# на компьютере, в папке бота
.venv\Scripts\python -m piper.download_voices ru_RU-irina-medium --download-dir models\piper
.venv\Scripts\python -c "from faster_whisper import download_model; download_model('small', output_dir='models/whisper-small')"
scp -r models root@1.2.3.4:~/claude-lab/telegram-bot/
```

Затем на сервере: в `.env` поставьте `WHISPER_MODEL=/models/whisper-small`, выполните
`chown -R 1000:1000 models` и `docker compose restart`.

## 6. Дневной лимит расходов и уведомления

Чтобы расходы на Claude не вышли из-под контроля, у бота есть **дневной лимит** (`DAILY_BUDGET_USD`, по умолчанию $1).

Укажите в настройках **свой Telegram ID** — `ADMIN_USER_ID` (как узнать ID — шаг 3.7). Тогда бот будет писать вам лично:

- **⚠️ на 80% лимита** — предупреждение: «Расходы на Claude сегодня: $0.81 из $1.00 (81%)»;
- **⛔ на 100%** — «Дневной лимит исчерпан» и кнопки **«+$0.50», «+$1», «+$2»** — поднять лимит **только на сегодня**.
  Нажимать их можете только вы.

Когда лимит исчерпан, Claude не отвечает до полуночи по Москве (семье бот вежливо об этом скажет).
Продолжают работать: покупки, напоминания, тренажёр для Никиты, добавление покупок голосом.
В полночь лимит обновляется сам. Сколько потрачено и сколько осталось — в «⚙️ Настройки».

Каждое уведомление приходит один раз в день. Если вы подняли лимит и он снова закончился — придёт новое.

## 9. Как устроен код (для урока)

```
telegram-bot/
├── main.py                 ← запуск: python main.py
├── start-bot.bat           ← запуск двойным щелчком на Windows
├── requirements.txt        ← библиотеки для работы
├── requirements-dev.txt    ← + библиотеки для тестов
├── requirements-voice.txt  ← голос (необязательно)
├── Dockerfile              ← образ для сервера
├── docker-compose.yml      ← запуск на сервере: автозапуск, папки data и models
├── .env.example            ← образец настроек для сервера (без ключей)
├── family_bot/
│   ├── app.py              ← собирает бота, меню команд, описание, служба напоминаний
│   ├── config.py           ← читает настройки из переменных окружения
│   ├── handlers.py         ← кнопки меню, команды, кнопки под сообщениями, диалог
│   ├── keyboards.py        ← все кнопки
│   ├── assistant.py        ← разговор с Claude: поиск, инструменты, ошибки, расходы
│   ├── tools.py            ← инструменты для Claude: покупки, напоминания, карточка рецепта
│   ├── family.py           ← сведения о семье и инструкции для Claude
│   ├── recipes.py          ← карточка рецепта
│   ├── media.py            ← видео/аудио-подборки, проверка ссылок, фото из Wikimedia Commons
│   ├── reminders.py        ← отправка напоминаний и рассылок в нужное время
│   ├── schedule.py         ← расписание повторов: каждый день, будни, выходные, неделя
│   ├── voice.py            ← голос: распознавание (Whisper) и озвучка (Piper)
│   ├── budget.py           ← дневной лимит и уведомления хозяину
│   ├── backup.py           ← ежедневные резервные копии базы
│   ├── models.py           ← модели Claude для «⚙️ Настройки»
│   ├── multiplication.py   ← тренажёр умножения
│   ├── storage.py          ← база данных SQLite: история, покупки, напоминания, расходы
│   ├── pricing.py          ← подсчёт стоимости запросов
│   ├── timeutil.py         ← время по Краснодару
│   └── texts.py            ← тексты бота
└── tests/                  ← тесты
```

Как бот выполняет просьбу «напомни Вике в 17:30 забрать Катю»:

```
Вы пишете в Telegram
  → aiogram получает сообщение (handlers.py), проверяет, что вы из семьи
  → FamilyAssistant берёт из базы последние сообщения и добавляет строку
    «[Сейчас 4 ноября, 15:00. Пишет: Сергей. В боте: Сергей, Вика]» (assistant.py)
  → Claude отвечает: «вызови create_reminder(текст, 2026-11-04 17:30, Вика)»
  → бот проверяет время и находит Вику, записывает в базу (tools.py, storage.py)
  → результат «Напоминание создано» уходит обратно Claude
  → Claude пишет: «Напомню Вике сегодня в 17:30» — вы видите это в Telegram
  → в 17:30 служба напоминаний (reminders.py) присылает Вике сообщение с кнопками
```

Почему так:
- **Claude не выполняет действия сам** — он только просит бота вызвать инструмент. Бот проверяет данные (время не в прошлом, человек существует) и выполняет. Так безопаснее.
- **Поиск в интернете делают серверы Anthropic** — бот лишь разрешает Claude искать (не больше 3 поисков за ответ).
- **Ссылки сверяются с результатами поиска** — так в чат не попадут выдуманные адреса.
- **Примеры на умножение без Claude** — языковая модель иногда ошибается в арифметике. Python не ошибается, а ещё это бесплатно и мгновенно.
- **Защита от ложных отказов** (только для Sonnet и Opus) — если фильтры Claude по ошибке откажут в ответе, сервер Anthropic сам повторит запрос на подходящей модели (параметр `fallbacks: "default"`). Для Haiku такой возможности у Anthropic нет — бот просто вежливо скажет, что ответить не может.
- **Дата и время передаются в каждом сообщении**, а не в общих инструкциях — так инструкции одинаковые и кэшируются, что дешевле.

## 10. Тесты

Тесты **не ходят в интернет и не тратят деньги**: Claude и Telegram в них подменены заглушками.
Ключи для тестов не нужны.

```powershell
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest
```

Что проверяется (315 тестов; без голосовых библиотек тест кодирования звука пропускается):
- настройки: без ключей — понятная ошибка, ключи не попадают в логи;
- запрос к Claude: модель, «старание», кэш, защита от отказов, набор инструментов;
- инструменты: покупки, напоминания (себе и Вике, время в прошлом, неизвестный человек);
- повторяющиеся напоминания и рассылки: расписание (каждый день, будни, выходные, неделя), перенос на следующий день,
  один раз после простоя, новый выпуск от Claude без повторов, кнопка «🔕», лимит 10 на человека,
  обновление старой базы без потери данных;
- рецепты: карточка, фото по ссылке только из настоящего поиска, защита HTML;
- видео и аудио: выдуманные ссылки отбрасываются, Claude просят поискать ещё;
- фото мест: разбор ответа Wikimedia Commons, отсев схем и мелких картинок, подписи авторов, запасной вариант, если альбом не отправился;
- поиск: ссылки на источники, продолжение долгого поиска, работа при отключённом поиске;
- дневной лимит: предупреждение на 80%, уведомление на 100% один раз, кнопки «+$» только для хозяина, сброс в полночь;
- голосовые: скачивание и распознавание, ответ текстом и голосом, выключатель в настройках, «Прочитать вслух»,
  голос в режиме рецепта и покупок, ошибки; кодирование в формат голосовых Telegram — по-настоящему;
- резервные копии: рабочая копия базы, удаление старых, время запуска, отправка в Telegram;
- файлы для сервера: автозапуск в docker-compose, бот не от root, ключи не попадают в образ и в git;
- выбор модели в настройках: кнопки, сохранение после перезапуска, модель не меняется посреди ответа, цена считается по каждой модели;
- ошибки Claude (неверный ключ, нет денег, нет сети, перегрузка, отказ) — понятные сообщения;
- бот целиком — от сообщения или нажатия кнопки в Telegram до ответа — для каждого раздела;
- служба напоминаний: отправка вовремя, пометка об опоздании, заблокированный бот;
- игра-тренажёр: варианты ответов, баллы, итог;
- настоящий SDK `anthropic` формирует правильные HTTP-запросы (подменена только сеть);
- в файлах проекта нет настоящих ключей.

## 11. Частые ошибки

| Что видите | Что делать |
|---|---|
| `python` открывает Microsoft Store или «не является командой» | Установите Python с галочкой «Add python.exe to PATH» (шаг 3.1) |
| `Ошибка настройки: Не заданы переменные окружения` | Задайте ключи (шаг 3.5). После `setx` откройте **новое** окно PowerShell |
| `TELEGRAM_BOT_TOKEN не похож на токен` / `Telegram не принял токен` | Скопируйте токен заново из @BotFather целиком, без пробелов и кавычек внутри |
| `Не получилось подключиться к Telegram` | Проверьте интернет и доступ к Telegram |
| `No module named ...` после обновления бота | Повторите шаг 3.4 (установка библиотек) |
| Бот пишет «Claude не принял API-ключ» | Проверьте `ANTHROPIC_API_KEY`, при необходимости создайте новый ключ |
| Бот пишет «На балансе Claude Console закончились деньги» | Пополните баланс в Claude Console → Billing |
| Бот пишет «Дневной лимит расходов исчерпан» | Подождите до завтра или увеличьте `DAILY_BUDGET_USD` |
| Рецепт пришёл без фото | У сайта нет картинки для превью или поиск отключён. Нажмите «🔄 Другой рецепт» |
| «Фото по запросу не нашлось» / «Не получилось загрузить фото» | Попросите по-другому («фото набережной Геленджика»). Проверьте, что с компьютера открывается commons.wikimedia.org |
| «Не знаю, кому отправить: Вика» | Вика должна один раз нажать «Старт» в боте (шаг 3.8) |
| Напоминание не пришло вовремя | Бот был выключен — оно придёт сразу после включения. Для надёжности — сервер (раздел 4) |
| Бот молчит | Окно с ботом открыто? Компьютер не спит? Бот не запущен где-то ещё? Загляните в `bot.log` |
| В логе `TelegramConflictError` | Бот запущен в двух местах. Оставьте одну копию |
| Бот пишет «Claude отказал в доступе (403)» | Проверьте ключ. Если ключ в порядке — Anthropic не поддерживает доступ из страны, где стоит сервер (раздел 4) |
| На сервере `PermissionError: … /data/…` | Не выполнен шаг 4.5: `chown -R 1000:1000 data models` |
| `docker compose up --build` не скачивает базовый образ | Подключите зеркало `mirror.gcr.io` (шаг 4.6) |
| «Голосовые сообщения пока выключены» | Установите голос (раздел 5) или проверьте `VOICE=1` |
| «Не получилось распознать голосовое» / в журнале «Модель … не загрузилась» | Модели не скачались — раздел 5, «Если сервер не может скачать модели» |
| Уведомления о лимите не приходят | Задайте `ADMIN_USER_ID` и один раз нажмите «Старт» в боте |

## 12. Безопасность и данные

- Ключи берутся **только из переменных окружения**. В коде и в файлах проекта их нет.
- Тест `tests/test_no_secrets.py` ищет в проекте строки, похожие на настоящие ключи, и падает, если найдёт.
- **`family_bot.db`** хранит семейные данные: историю разговоров, покупки, напоминания. **`bot.log`** — журнал работы (тексты сообщений туда не пишутся).
  Оба файла в `.gitignore` и в репозиторий не попадают. Делайте копию `family_bot.db`, если данные важны.
- Если задан `ALLOWED_USER_IDS`, чужие люди не могут ни писать боту, ни нажимать его кнопки.
- На сервере ключи лежат только в файле `.env` (`chmod 600` — читает только владелец). В образ Docker и в git он не попадает.
  Бот в контейнере работает не от администратора (root).
- **Голос не уходит в интернет**: звук распознаётся на вашем сервере, в Claude отправляется только текст.
- Резервные копии (`data/backups`) содержат семейные данные. Копия в Telegram — только если вы сами включили `BACKUP_TO_TELEGRAM=1`.
- Не отправляйте скриншоты с ключами и не вставляйте ключи в чаты.
- Если ключ утёк: токен Telegram отзовите в @BotFather (раздел 1), ключ Claude удалите в Console на странице [API keys](https://platform.claude.com/settings/keys) и создайте новый.
