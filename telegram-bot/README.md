# 🏠 «Семейный помощник» — Telegram-бот на Claude

Бот для семьи из Краснодара: Сергей, Вика, Никита (8 лет) и Катя (3 года).
Отвечает на любые вопросы с помощью Claude, помнит последние сообщения,
даёт Никите примеры на умножение и придумывает, чем заняться на выходных.

| Команда | Что делает | Тратит деньги на Claude? |
|---|---|---|
| `/start` | Приветствие и список команд | нет |
| любое сообщение | Ответ Claude с учётом последних 20 сообщений | да |
| `/primery` | 10 примеров на умножение для Никиты, ответы спрятаны под спойлер | **нет** — примеры считает сам Python |
| `/primery 7` | 10 примеров только на 7 (можно любое число от 2 до 9) | нет |
| `/vyhodnye` | 5 идей на выходные для всей семьи с учётом сезона и возраста детей | да |
| `/sbros` | Забыть историю разговора | нет |

Сделано на **Python** + **aiogram 3** (библиотека для Telegram-ботов) + **anthropic** (официальная библиотека Claude API).
Модель — **Claude Haiku 5.5** (`claude-haiku-5-5`), самая экономная из актуальных.

## 1. Получаем токен бота у @BotFather

Токен — это «пароль» бота. С ним программа может отвечать от имени бота.

1. Откройте Telegram и найдите **@BotFather** (у него синяя галочка).
2. Нажмите «Старт» и отправьте команду `/newbot`.
3. BotFather спросит **имя** — оно будет видно в чате. Например: `Семейный помощник`.
4. Потом спросит **username** — адрес бота. Он должен заканчиваться на `bot` и быть свободным.
   Например: `family_helper_krd_bot`. Если занято — придумайте другой.
5. BotFather пришлёт сообщение с токеном вида `1234567890:AAH...` (длинная строка через двоеточие).
   **Это и есть `TELEGRAM_BOT_TOKEN`.** Скопируйте его целиком.

> 🔒 Токен никому не показывайте и не выкладывайте в интернет.
> Если он «утёк» — в @BotFather: `/mybots` → ваш бот → **API Token** → **Revoke current token**.
> Старый токен перестанет работать, BotFather выдаст новый.

По желанию там же: `/setuserpic` — аватарка, `/setdescription` — описание бота.

Источник: [официальная инструкция Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

## 2. Получаем API-ключ в Claude Console

API-ключ — это «пароль» для доступа к Claude из программы. Оплата идёт за каждый запрос.

1. Откройте **[platform.claude.com](https://platform.claude.com/)** и войдите или зарегистрируйтесь.
2. Пополните баланс в разделе **Billing**. Начните с небольшой суммы — для семейного бота её хватит надолго (см. [раздел 6](#6-сколько-это-стоит)).
3. Откройте страницу **[API keys](https://platform.claude.com/settings/keys)** (`platform.claude.com/settings/keys`).
4. Нажмите **Create key**, назовите ключ, например `family-bot`, и создайте его.
5. Скопируйте ключ — он начинается с `sk-ant-`. **Ключ показывают только один раз.**
   Потеряли — просто создайте новый.
   **Это и есть `ANTHROPIC_API_KEY`.**

Важно знать:

- **Подписка Claude Pro/Max и API — это разные вещи.** Подписка не оплачивает запросы через API, баланс в Console пополняется отдельно.
  Источник: [справка Anthropic](https://support.claude.com/en/articles/9876003).
- **Страны.** У Anthropic есть официальный список стран, откуда поддерживается доступ к API.
  На момент написания (ноябрь 2026) **России в этом списке нет**.
  Пользоваться API нужно по правилам Anthropic.
  Источник: [Supported regions](https://platform.claude.com/docs/en/api/supported-regions).

Источник по ключам: [Get your Claude API key](https://platform.claude.com/docs/en/get-api-key).

## 3. Запуск на Windows по шагам

### Шаг 3.1. Установите Python

1. Скачайте Python **3.12 или 3.13** с [python.org/downloads/windows](https://www.python.org/downloads/windows/).
2. При установке **обязательно поставьте галочку «Add python.exe to PATH»**, потом нажмите «Install Now».
3. Проверьте: откройте PowerShell (Пуск → наберите `PowerShell` → Enter) и введите:

   ```powershell
   python --version
   ```

   Должно показать `Python 3.13.…`. Если открылся Microsoft Store — Python не установлен или не стоит галочка PATH. Переустановите с галочкой.

### Шаг 3.2. Скачайте проект

На странице репозитория на GitHub нажмите зелёную кнопку **Code** → **Download ZIP**.
Распакуйте архив, например, в `C:\bots\`. Нужная папка — `telegram-bot`.

### Шаг 3.3. Откройте PowerShell в папке бота

Откройте папку `telegram-bot` в Проводнике, щёлкните по адресной строке сверху,
наберите `powershell` и нажмите Enter. Откроется окно PowerShell сразу в этой папке.

### Шаг 3.4. Установите библиотеки

Создаём «виртуальное окружение» — отдельную папку `.venv` с библиотеками только для этого бота:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Займёт 1–2 минуты. Это нужно сделать один раз.

### Шаг 3.5. Задайте ключи (переменные окружения)

Ключи **не пишутся в файлы проекта**. Их берут из переменных окружения Windows.

**Вариант А — навсегда (удобнее).** Выполните в PowerShell, подставив свои значения:

```powershell
setx TELEGRAM_BOT_TOKEN "сюда_токен_от_BotFather"
setx ANTHROPIC_API_KEY "сюда_ключ_из_Claude_Console"
```

После этого **закройте PowerShell и откройте заново** (шаг 3.3) — `setx` действует только на новые окна.
Значения сохраняются в настройках вашей учётной записи Windows, а не в папке проекта.

Проверить можно так (покажет первые символы, а не весь ключ):

```powershell
$env:ANTHROPIC_API_KEY.Substring(0, 10)
```

**Вариант Б — только для текущего окна** (закрыли окно — ключи забылись):

```powershell
$env:TELEGRAM_BOT_TOKEN = "сюда_токен_от_BotFather"
$env:ANTHROPIC_API_KEY = "сюда_ключ_из_Claude_Console"
```

### Шаг 3.6. Запустите бота

```powershell
.venv\Scripts\python main.py
```

Или просто дважды щёлкните файл **`start-bot.bat`** в папке бота.

Если всё хорошо, появится строка:

```
... INFO family_bot.app: Бот @family_helper_krd_bot запущен. Модель: claude-haiku-5-5. Остановить: Ctrl+C
```

Откройте своего бота в Telegram и отправьте `/start`. 🎉

**Бот работает, пока открыто это окно.** Остановить — `Ctrl+C` или закрыть окно.

### Шаг 3.7. Пустите только семью (рекомендуется)

Сейчас бот отвечает **любому**, кто его найдёт, и тратит ваши деньги. Ограничим доступ:

1. Узнайте свой Telegram ID. Остановите бота (`Ctrl+C`) и выполните:

   ```powershell
   $env:ALLOWED_USER_IDS = "1"
   .venv\Scripts\python main.py
   ```

   Напишите боту что угодно — он ответит: «Ваш Telegram ID: 123456789». Пусть то же сделает Вика.
2. Сохраните ID через запятую и перезапустите бота в **новом** окне PowerShell
   (если ключи задавали вариантом Б — задайте их в новом окне снова):

   ```powershell
   setx ALLOWED_USER_IDS "123456789,987654321"
   ```

Теперь чужим бот отвечает только «это семейный бот» — без запроса к Claude, бесплатно.

## 4. Как сделать, чтобы бот работал 24/7

Бот работает, только пока запущена программа. Вот варианты, от простого к надёжному.
Бот сам обращается к Telegram за новыми сообщениями, поэтому **белый IP, домен и HTTPS не нужны** ни в одном варианте.

| Вариант | Деньги | Надёжность | Сложность |
|---|---|---|---|
| **А. Домашний компьютер** | бесплатно (только электричество) | пока ПК включён и есть интернет | легко |
| **Б. Мини-ПК или Raspberry Pi дома** | разовая покупка, мало электричества | как у домашнего интернета и света | средне |
| **В. VPS (виртуальный сервер)** | ежемесячная плата провайдеру | высокая, работает круглосуточно | средне — нужны азы Linux |
| **Г. Облачная платформа для приложений** (PaaS) | от бесплатно до платно, условия часто меняются | высокая | средне |

### А. Домашний компьютер с Windows

1. Отключите спящий режим: Параметры → Система → Питание → настройки сна → **Никогда**.
2. Автозапуск через **Планировщик заданий** (Пуск → «Планировщик заданий»):
   «Создать простую задачу» → триггер **«При входе в Windows»** → действие **«Запустить программу»** →
   выберите файл `start-bot.bat` из папки бота.
3. Минусы: выключили ПК, пропал свет или интернет, Windows ушла в обновление — бот молчит.

### Б. Мини-ПК или Raspberry Pi

Маленький компьютер, который тихо работает в углу и потребляет мало энергии.
Ставите на него Linux и запускаете бота как службу — см. вариант В, шаги те же.

### В. VPS — самый надёжный вариант

VPS — это ваш личный компьютер в дата-центре, который никогда не выключается.
Для этого бота хватит самого маленького тарифа (1 ядро, 1 ГБ памяти).
Цены и условия смотрите у провайдера.

Пример настройки на Ubuntu (команды выполняются на сервере):

```bash
# 1. Python и проект
sudo apt update && sudo apt install -y python3 python3-venv git
git clone https://github.com/sergey-bagaliy/claude-lab.git
cd claude-lab/telegram-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2. Ключи — в отдельный файл ВНЕ проекта, читать может только root
sudo nano /etc/family-bot.env
sudo chmod 600 /etc/family-bot.env
```

Содержимое `/etc/family-bot.env`:

```
TELEGRAM_BOT_TOKEN=сюда_токен
ANTHROPIC_API_KEY=сюда_ключ
ALLOWED_USER_IDS=123456789,987654321
```

Служба, которая сама поднимет бота после перезагрузки или сбоя. Файл `/etc/systemd/system/family-bot.service`
(замените `/home/ubuntu` на свою папку и `ubuntu` на своего пользователя):

```ini
[Unit]
Description=Telegram bot "Semeyny pomoshnik"
After=network-online.target
Wants=network-online.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/claude-lab/telegram-bot
EnvironmentFile=/etc/family-bot.env
ExecStart=/home/ubuntu/claude-lab/telegram-bot/.venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now family-bot   # включить и запустить
sudo systemctl status family-bot         # работает ли
journalctl -u family-bot -f              # смотреть логи (выход — Ctrl+C)
```

### Г. Облачные платформы (PaaS)

Сервисы, куда загружаешь код, а они сами его запускают. Ключи задаются в их панели
как переменные окружения. Бесплатные тарифы и цены часто меняются, поэтому проверяйте их
на сайте платформы. Заранее уточните, принимают ли они вашу карту.

### Важно для любого варианта

- **Запускайте бота только в одном месте.** Две копии с одним токеном мешают друг другу:
  в логе будет ошибка `TelegramConflictError`.
- **Память диалогов хранится в оперативной памяти**, после перезапуска бот «забывает» разговоры. Для семейного бота это нормально.

## 5. Настройки

Все настройки задаются переменными окружения. В коде ключей нет.

| Переменная | Обязательна | Что это | По умолчанию |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | **да** | Токен от @BotFather | — |
| `ANTHROPIC_API_KEY` | **да** | Ключ из Claude Console | — |
| `ALLOWED_USER_IDS` | рекомендуется | Telegram ID членов семьи через запятую. Пусто — бот отвечает всем | пусто |
| `CLAUDE_MODEL` | нет | Модель Claude. Например, `claude-sonnet-5-5` — умнее, но в 20 раз дороже | `claude-haiku-5-5` |
| `MEMORY_SIZE` | нет | Сколько последних сообщений помнить в каждом чате (вопросы + ответы) | `20` |

Характер бота и сведения о семье — в файле `family_bot/family.py`. Когда дети подрастут, поменяйте там возраст.

## 6. Сколько это стоит

Цены Claude Haiku 5.5 (для запросов до 100 000 токенов):
**$0.10 за 1 млн входящих токенов** и **$0.50 за 1 млн исходящих**.
Источник: [официальные цены](https://platform.claude.com/docs/en/about-claude/pricing).

Токен — это кусочек слова. Один вопрос с историей разговора — это примерно 2 000 токенов на вход и около 400 на выход.

**Моя грубая оценка:** ~$0.0004 за вопрос, то есть **около 2 000 вопросов на $1**.
Реальный расход виден в Claude Console. Кроме того, бот пишет в лог число токенов каждого ответа.

Что уже сделано для экономии:
- самая дешёвая модель (Haiku 5.5) и низкий уровень «старания» (`effort: low`);
- `/primery` работает вообще без Claude;
- память ограничена 20 сообщениями, поэтому вопросы не «раздуваются»;
- чужие люди не тратят ваши деньги, если задан `ALLOWED_USER_IDS`.

Telegram-боты бесплатны.

## 7. Как устроен код (для урока)

```
telegram-bot/
├── main.py                 ← запуск: python main.py
├── start-bot.bat           ← запуск двойным щелчком на Windows
├── requirements.txt        ← библиотеки для работы
├── requirements-dev.txt    ← + библиотеки для тестов
├── family_bot/
│   ├── app.py              ← собирает бота и запускает
│   ├── config.py           ← читает настройки из переменных окружения
│   ├── handlers.py         ← команды Telegram: /start, /primery, /vyhodnye, /sbros, диалог
│   ├── assistant.py        ← запросы к Claude, обработка ошибок
│   ├── memory.py           ← память последних сообщений
│   ├── family.py           ← сведения о семье и инструкции для Claude
│   ├── multiplication.py   ← примеры на умножение
│   └── texts.py            ← тексты бота, разбивка длинных ответов
└── tests/                  ← тесты
```

Путь одного сообщения:

```
Вы пишете в Telegram
  → aiogram получает сообщение (handlers.py)
  → проверка: член семьи? (ALLOWED_USER_IDS)
  → FamilyAssistant берёт последние сообщения из памяти (memory.py)
  → отправляет в Claude: инструкции о семье + история + вопрос (assistant.py)
  → ответ сохраняется в память и уходит вам в Telegram
```

Почему так:
- **Память** — Claude сам ничего не помнит между запросами. Поэтому бот каждый раз отправляет ему последние сообщения разговора.
- **Примеры на умножение без Claude** — языковая модель иногда ошибается в арифметике. Python не ошибается, а ещё это бесплатно и мгновенно.
- **Ответы Claude отправляются простым текстом** — так случайный символ в ответе не сломает отправку.

## 8. Тесты

Тесты **не ходят в интернет и не тратят деньги**: Claude и Telegram в них подменены заглушками.
Ключи для тестов не нужны.

```powershell
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest
```

Что проверяется:
- настройки: без ключей — понятная ошибка, ключи не попадают в логи;
- запрос к Claude: правильная модель и параметры, память, разные чаты не смешиваются;
- ошибки Claude (неверный ключ, нет денег, нет сети, перегрузка, отказ) превращаются в понятные сообщения;
- бот целиком — от сообщения Telegram до ответа — для каждой команды;
- доступ только для семьи;
- примеры на умножение: без повторов, ответы верные;
- настоящий SDK `anthropic` формирует правильный HTTP-запрос (подменена только сеть);
- в файлах проекта нет настоящих ключей.

## 9. Частые ошибки

| Что видите | Что делать |
|---|---|
| `python` открывает Microsoft Store или «не является командой» | Установите Python с галочкой «Add python.exe to PATH» (шаг 3.1) |
| `Ошибка настройки: Не заданы переменные окружения` | Задайте ключи (шаг 3.5). После `setx` откройте **новое** окно PowerShell |
| `TELEGRAM_BOT_TOKEN не похож на токен` / `Telegram не принял токен` | Скопируйте токен заново из @BotFather целиком, без пробелов и кавычек внутри |
| `Не получилось подключиться к Telegram` | Проверьте интернет и доступ к Telegram |
| Бот пишет «Claude не принял API-ключ» | Проверьте `ANTHROPIC_API_KEY`, при необходимости создайте новый ключ |
| Бот пишет «На балансе Claude Console закончились деньги» | Пополните баланс в Claude Console → Billing |
| Бот молчит | Окно с ботом открыто? Компьютер не спит? Бот не запущен где-то ещё? |
| В логе `TelegramConflictError` | Бот запущен в двух местах. Оставьте одну копию |

## 10. Безопасность ключей

- Ключи берутся **только из переменных окружения**. В коде и в файлах проекта их нет.
- `.gitignore` не даёт случайно закоммитить файлы `.env` и похожие.
- Тест `tests/test_no_secrets.py` ищет в проекте строки, похожие на настоящие ключи, и падает, если найдёт.
- Не отправляйте скриншоты с ключами и не вставляйте ключи в чаты.
- Если ключ утёк: токен Telegram отзовите в @BotFather (раздел 1), ключ Claude удалите в Console на странице [API keys](https://platform.claude.com/settings/keys) и создайте новый.
