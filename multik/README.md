# «Семья едет в горы» — мультфильм, нарисованный кодом

Короткий добрый мультфильм про нашу семью: папа на сноуборде, мама Вика на лыжах,
Никита (8 лет) и Катя (3 года) на ватрушке.

- **Видео:** `multik.mp4` — 42 секунды, 1920×1080, 30 кадров в секунду, со звуком.
- **Версия для браузера:** `index.html` — открывается двойным щелчком, без интернета.
- Всё нарисовано кодом: ни одной картинки из интернета. Музыка тоже сгенерирована кодом,
  чужих треков нет.

## Как посмотреть

1. **Видео** — откройте `multik.mp4` в любом плеере (или прямо на GitHub).
2. **В браузере** — откройте `index.html` (Chrome, Edge, Firefox, Safari).
   Нажмите «▶ Смотреть мультфильм».
   - Пробел — пауза или продолжить, стрелки ← → — перемотка на 2 секунды.
   - Кнопки под плеером переключают сцены, 🔊 включает и выключает звук.

## Как это сделано

Представьте покадровую мультипликацию, только вместо художника — программа.

1. **Рисование.** Каждый персонаж собран из простых фигур: круг — голова, скруглённый
   прямоугольник — куртка, толстые линии — руки и ноги. Всё рисуется на холсте
   HTML Canvas размером 1920×1080. Поза задаётся числами: угол руки, присед, наклон.
2. **Время.** Главная идея: кадр зависит **только от времени**. Функция «нарисуй кадр
   на секунде 19,3» всегда рисует одно и то же — папа как раз влетает в сугроб.
   Поэтому браузер и видео совпадают кадр в кадр, а перемотка работает мгновенно.
3. **Музыка.** В `js/music.js` — маленький синтезатор: ноты записаны списком
   («соль, до, ре, ми…»), код сам считает звуковую волну. Весёлая мелодия на поездку,
   барабанная дробь перед трамплином, свисток при падении, «бух» в сугроб,
   «хохочущая» тема, а у камина — музыкальная шкатулка.
4. **Видео.** Скрипт `render/render.js` открывает страницу в невидимом браузере
   (Chromium через Playwright), по очереди рисует 1260 кадров и передаёт их в ffmpeg,
   который склеивает их со звуком в `multik.mp4`.

## Что где лежит

```
multik/
├── index.html        — страница-плеер (открыть в браузере)
├── multik.mp4        — готовое видео
├── js/
│   ├── draw.js       — «кисти»: персонажи, машина, ёлки, горы, облачка реплик
│   ├── scenes.js     — сцены, тексты реплик, порядок и длительность сцен
│   ├── music.js      — музыка и звуки
│   └── player.js     — кнопки плеера, звук в браузере
├── render/render.js  — сборка видео
├── fonts/            — шрифт Rubik (лицензия OFL, можно свободно использовать)
└── package.json
```

## Как поменять мультфильм

Файлы — обычный текст, их можно править в любом редакторе (например, бесплатный
VS Code). После правки обновите `index.html` в браузере — изменения сразу видны.

### Поменять реплики и титры

В начале `js/scenes.js` есть блок `TEXT` — все надписи собраны там:

```js
momGo: 'Догоняйте!',
dadPlan: 'Я так и задумал!',
end: 'Наша семья'
```

Например, чтобы в конце было «Семья Ивановых», замените строку на
`end: 'Семья Ивановых'`.

### Поменять цвета одежды и рост

В `js/draw.js` найдите `M.CHAR`. Там у каждого члена семьи свои размеры и цвета:

```js
mom: { leg: 90, torso: 86, head: 44, w: 72, ..., jacket: '#ee4d86', ... }
```

- `jacket` — цвет куртки, `hat` — шапки, `pants` — штанов (цвет в формате `#RRGGBB`,
  удобно подбирать на сайте по запросу «color picker»).
- `leg`, `torso`, `head` — длина ног, туловища и размер головы. Мама специально
  ниже папы: ноги 90 против 118.

### Поменять длительность или порядок сцен

Внизу `js/scenes.js` есть список `M.SCENES`:

```js
{ name: 'Спуск', start: 13, end: 16, draw: sceneRace },
```

`start` и `end` — секунды от начала фильма. Внутри каждой сцены время отсчитывается
от её начала, поэтому сцену можно сдвинуть целиком. Если меняете время —
поправьте общую длину `M.DURATION`, переходы `M.TRANSITIONS` и расписание музыки
в `js/music.js` (раздел «РАСПИСАНИЕ»), чтобы звук совпадал с картинкой.

### Добавить свою сцену

1. В `js/scenes.js` напишите функцию, например:

```js
function sceneSnowman(ctx, lt) {           // lt — секунды от начала сцены
  ctx.fillStyle = '#dff3ff'; ctx.fillRect(0, 0, 1920, 1080);
  M.person(ctx, 'katya', { t: lt, mouth: 'laugh', eyes: 'happy' }); // Катя смеётся
}
```

   Персонажа ставят на место через `M.at(ctx, x, y, поворот, масштаб, () => { ... })`.
2. Добавьте её в `M.SCENES` и сдвиньте время следующих сцен.

### Поменять музыку

В `js/music.js` мелодия записана как список `[длительность, нота]`, например
`[1, 'G4'], [.5, 'C5']` — «соль на целую долю, до на половину». Можно вписать
другую мелодию или убрать звук вовсе: в браузере есть кнопка 🔊.

## Как пересобрать видео

Нужны: [Node.js](https://nodejs.org) 18 или новее и [ffmpeg](https://ffmpeg.org).

```bash
cd multik
npm install                  # установит Playwright
npx playwright install chromium
npm run render               # соберёт multik.mp4 (несколько минут)
```

Проверить один кадр, не собирая всё видео:

```bash
node render/render.js --still 19.5          # кадр на 19,5 секунде → render/still-19.5.png
node render/render.js --stills 2,10,20      # несколько кадров
node render/render.js --from 16 --to 22 --out test.mp4   # кусочек видео
```
